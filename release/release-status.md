# Release Status

Quantum Readiness for Space Communications is maintained as a
documentation-first public framework.

Current source version: **0.2.6**

Published distribution identity is recorded on
[GitHub Releases](https://github.com/Bridge-Node-7/quantum-readiness-space-communications/releases/latest).
A source version is a published release only when its matching tag and GitHub
Release exist.

Published releases preserve explicit identity, source traceability,
deterministic packaging, reproducible validation, methodology limits, and known
limitations.

A release does not certify a system, approve deployment, or establish
operational readiness.
