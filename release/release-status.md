# Release Status

Quantum Readiness for Space Communications is maintained as a
documentation-first public framework.

Current source version: **0.2.4**

Latest published GitHub Release: **v0.2.3**

Source version 0.2.4 is not represented as a published release until the
corresponding tag and GitHub Release exist.

Published releases preserve explicit identity, source traceability,
deterministic packaging, reproducible validation, methodology limits, and known
limitations.

A release does not certify a system, approve deployment, or establish
operational readiness.
