# Accessibility and Mobile Use

The repository is text-first and designed to remain usable without scripts or proprietary software.

## Narrow-screen use

Some registers contain several fields. On narrow screens:

1. Read one row at a time.
2. Treat the leftmost stable ID as the record key.
3. Copy a template into an approved controlled environment before entering real data.
4. Split a row into a vertical field list when horizontal scrolling impedes review.

## Assistive-technology considerations

- Preserve heading order.
- Keep stable IDs in spoken labels.
- Do not communicate status through color alone.
- Expand acronyms on first use.
- Provide meaningful link text.
- Announce table purpose before reading cell values.
- Record any accessibility limitation in the review record.

## Using the templates

The published examples are fictional. For real work, use an environment
appropriate to the information being reviewed and apply the same accessibility
guidance there.
