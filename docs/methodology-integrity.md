# Methodology Integrity Invariants

A valid repository revision must preserve all of these invariants:

1. No weighted aggregate readiness score.
2. Exposure severity and migration readiness have opposite, explicit orientations.
3. Evidence confidence remains separate from both.
4. Critical override conditions cannot be canceled by strengths elsewhere.
5. The readiness profile contains exactly ten domains.
6. The highest stage is named **Sustained and Reassessed**.
7. QKD and QRNG remain optional, context-dependent considerations.
8. Decision-support labels are explicitly non-authoritative.
9. Legacy version 0.1.5 scoring files point to the replacements.
10. Public claim boundaries prohibit certification and authorization claims.
11. This public framework does not include an assessment engine or workbook decision calculator.
12. Every public release includes integrity validation and a current status record.
